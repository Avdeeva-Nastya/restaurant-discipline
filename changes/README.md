# Отдельные файлы с изменениями

Каждый .patch — это изменения одного файла проекта относительно main (коммит f42084b).
Строки с "+" — добавлено, "-" — удалено. Применить: git apply changes/<файл>.patch

- 01-App.tsx.patch — flex-раскладка: страницы на всю рабочую область; фикс "Restaurant" -> "restaurant"
- 02-App.css.patch — стили контейнера рабочей области на всю высоту
- 03-Habits.tsx.patch — «Привычки»: лимит 3 в день, циклы 7/14/21, серии, награды, большая кнопка «+»
- 04-Habits.css.patch — светлый дизайн привычек, крупный шрифт, стили кнопки «+» (.hb-add)
- 05-Goals.tsx.patch — «Цели»: рабочие todo, лимит 3 цели в день, выполнение кликом, localStorage
- 06-Goals.css.patch — дизайн целей: светлая тема, читаемый шрифт, прокрутка на всю область
- 07-Restaurant.css.patch — мелкие правки стилей ресторана
- 08-package-lock.json.patch — обновление lock-файла (не влияет на код)
